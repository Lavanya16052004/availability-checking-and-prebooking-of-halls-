# Room Availability Checking and Pre-Booking of Halls in VIIT

A full-stack web application developed for Vignan’s Institute of Information Technology (VIIT) to automate classroom and hall booking management. The system enables faculty and administrators to check room availability in real time and reserve halls efficiently through a centralized digital platform.

---

## Features

- Real-time room availability tracking
- Advance hall and classroom booking
- Role-based authentication for faculty and administrators
- Conflict prevention to avoid double bookings
- Interactive block-wise and floor-wise campus layout
- Real-time booking status updates
- Admin approval workflow
- Responsive and user-friendly interface

## System Modules

### User Authentication
Secure login system for administrators and faculty members.

### Room Availability Management
Displays real-time availability of classrooms, laboratories, seminar halls, and auditoriums.

### Booking Management
Allows users to reserve halls and classrooms in advance.

### Admin Dashboard
Enables administrators to monitor, approve, and manage booking requests.
